# ТРОН

Карточная игра на трёх рядах против компьютера: два выигранных раунда из трёх — победа.

## Как запустить

**На Android:** установите `dist/tron.apk`. Телефон попросит разрешить установку
из неизвестного источника — это нормально для приложений не из Google Play.

Самое простое — файл `dist/tron.html`: в нём вся игра вместе с картинками.
Скачайте его на телефон или компьютер и откройте в браузере. Интернет не нужен.

Можно открыть и `index.html` в папке проекта.
На телефоне держите экран горизонтально.

После изменения карт пересоберите однофайловую версию: `python3 tools/build_single.py`.

## Правила вкратце

Дуэль двух героинь, у каждой 30 здоровья.

- Каждый ход +1 кристалл маны (до 10) и одна новая карта. Мана восстанавливается в начале хода.
- Существа выходят на поле (до 7) и со следующего хода атакуют вражеских существ или героиню.
- Ключевые слова: Провокация, Рывок, Щит, Скрытность, Яд, Двойной удар, Вампиризм, Полёт.
- Боевой клич, Предсмертный хрип, эффекты в конце хода.
- У каждой героини своя сила (2 маны раз в ход), свои карты и своё поле со своими звуками.
- Особые эффекты: 💍 Брак, 🤰 Беременность, 📜 Долг, 💫 Оглушение.
- Кто ходит вторым, получает «Медяк» (+1 мана на один ход).

Колода — 30 карт: 6 карт героини и случайный набор общих карт по кривой маны.

## Атмосфера

- Поля героинь: ЗАГС, агентство недвижимости, ночной забег, декретная лаборатория — у каждого свои фоновые звуки.
- Заклинания-«погода» вызывают бурю на столе: ядовитую муть, ливень, пьяный угар или золотые искры.
- Свет переходит на сторону того, чей ход; факелы мерцают.
- Существа влетают на стол, бросаются в атаку, сгорают при гибели, над ними всплывает урон.
- Предметы по краям поля трескаются от ударов и заклинаний, их можно ломать и вручную.
- Звуки синтезируются в браузере, кнопка 🔊 выключает звук.

## Как добавить свою карту

1. Положите картинку в `img/cards/<id>.jpg` и уменьшенную копию (~300 px) в `img/cards/thumbs/<id>.jpg`.
2. Добавьте строку в `SHARED_CARDS` в `js/cards.js`:

```js
M('my_hero', 'Мой герой', 4, 3, 5, { ...IMG('my_hero'), rarity: 'epic', kw: ['taunt'], bc: [{ e: 'dmg', n: 2, t: 'enemyMinion' }] }),
Sp('my_spell', 'Моё заклинание', 3, [{ e: 'aoe', n: 2, who: 'enemyMinions' }], { ...IMG('my_spell'), rarity: 'rare' }),
```

`M(id, имя, мана, атака, здоровье, …)` — существо, `Sp(id, имя, мана, [эффекты], …)` — заклинание.
Все эффекты перечислены в функции `effText` в `js/cards.js`, текст карты собирается из них автоматически.

## Файлы

- `js/cards.js` — все карты, фракции, способности
- `js/engine.js` — правила игры
- `js/ai.js` — компьютерный противник
- `js/ui.js` — интерфейс
- `css/style.css` — оформление

## Сборка APK

```bash
sudo apt-get install android-sdk-platform-23 aapt apksigner zipalign dalvik-exchange default-jdk
bash android/build_apk.sh        # → dist/tron.apk
```

APK подписывается ключом `android/debug.keystore` (пароль `android`). Ключ лежит в репозитории
специально: обновлённый APK ставится поверх старого, только если подписан тем же ключом.
Для публикации в Google Play нужен отдельный ключ, который хранят в секрете.
