# Трактирная Дуэль

Карточная игра на трёх рядах против компьютера: два выигранных раунда из трёх — победа.

## Как запустить

Откройте `index.html` в браузере (двойной щелчок). Сервер и установка не нужны.
На телефоне лучше держать экран горизонтально.

## Правила вкратце

- В начале партии — 10 карт, 2 из них можно заменить.
- За ход: сыграть карту, применить лидера (один раз за игру) или спасовать.
- Раунд заканчивается, когда спасовали оба. Побеждает тот, у кого больше сила на поле.
- Новые карты между раундами не выдаются — берегите руку.
- Ряды: ⚔️ ближний бой, 🏹 дальний бой, 🏰 осада.

Полные правила и описание способностей есть в игре (кнопка «Правила»), все карты — в «Коллекции карт».

## Как добавить свою карту

1. Положите картинку в `img/cards/<id>.jpg` и уменьшенную копию (~300 px) в `img/cards/thumbs/<id>.jpg`.
2. Добавьте строку в `SHARED_CARDS` в файле `js/cards.js`, например:

```js
U('my_hero', 'Мой герой', 6, 'melee', ['morale'], '🗡️', { ...IMG('my_hero'), rarity: 'epic', quote: '«Цитата»' }),
S('my_spell', 'damage', 'Моё заклинание', '🔥', { ...IMG('my_spell'), rarity: 'rare', value: 4 }),
```

`U(...)` создаёт отряд (id, название, сила, ряд, способности), `S(...)` — особую карту
(id, тип эффекта, название). Все способности перечислены в `ABILITIES`, все эффекты особых карт — в `SPECIAL_KINDS`.

## Файлы

- `js/cards.js` — все карты, фракции, способности
- `js/engine.js` — правила игры
- `js/ai.js` — компьютерный противник
- `js/ui.js` — интерфейс
- `css/style.css` — оформление
