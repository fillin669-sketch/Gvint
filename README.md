# ТРОН

Карточная игра на трёх рядах против компьютера: два выигранных раунда из трёх — победа.

## Как запустить

**На Android:** установите `dist/tron.apk`. Телефон попросит разрешить установку
из неизвестного источника — это нормально для приложений не из Google Play.

Самое простое — файл `dist/tron.html`: в нём вся игра вместе с картинками.
Скачайте его на телефон или компьютер и откройте в браузере. Интернет не нужен.

Можно открыть и `index.html` в папке проекта.
На телефоне держите экран горизонтально.

После изменения карт пересоберите однофайловую версию: `python3 tools/build_single.py`.

## Правила вкратце

- В начале партии — 10 карт, 2 из них можно заменить.
- За ход: сыграть карту, применить лидера (один раз за игру) или спасовать.
- Раунд заканчивается, когда спасовали оба. Побеждает тот, у кого больше сила на поле.
- Новые карты между раундами не выдаются — берегите руку.
- Ряды: ⚔️ ближний бой, 🏹 дальний бой, 🏰 осада.

## Атмосфера

- У каждой фракции своё поле (крепостной двор, лесная поляна, проклятый склеп, пристань) со своими фоновыми звуками.
  Звучит поле вашей фракции; в меню — трактир. Кнопка 🔊 выключает звук.
- Погода анимирована: в ближнем ряду — бурлящая муть, в дальнем — ливень, в осаде — пьяный угар.
- Свет переходит на сторону того, чей ход; во время непогоды поблёскивают молнии.
- На краю каждого ряда стоит предмет окружения (бочка, якорь, череп…). Удары по ряду его ломают.
  Предметы ничего не меняют в правилах — это атмосфера.
- Звуки синтезируются в браузере, аудиофайлов нет.

Полные правила и описание способностей есть в игре (кнопка «Правила»), все карты — в «Коллекции карт».

## Новые карты без картинок

В разделе «Коллекция карт → Новые карты» лежат 31 карта (Тёща, Батя с ремнём, гопники,
Бабки у подъезда, Шаурма с вокзала и др.). Пока у них вместо картинки значок.
Чтобы дать такой карте картинку, сохраните её как `img/cards/<id>.jpg` и уменьшенную копию
как `img/cards/thumbs/<id>.jpg`, где `<id>` подписан под картой в коллекции. Код менять не нужно.
В меню можно снять галочку «Новые карты в колоде», тогда играют только карты с картинками.

## Как добавить свою карту

1. Положите картинку в `img/cards/<id>.jpg` и уменьшенную копию (~300 px) в `img/cards/thumbs/<id>.jpg`.
2. Добавьте строку в `SHARED_CARDS` в файле `js/cards.js`, например:

```js
U('my_hero', 'Мой герой', 6, 'melee', ['morale'], '🗡️', { ...IMG('my_hero'), rarity: 'epic', quote: '«Цитата»' }),
S('my_spell', 'damage', 'Моё заклинание', '🔥', { ...IMG('my_spell'), rarity: 'rare', value: 4 }),
```

`U(...)` создаёт отряд (id, название, сила, ряд, способности), `S(...)` — особую карту
(id, тип эффекта, название). Все способности перечислены в `ABILITIES`, все эффекты особых карт — в `SPECIAL_KINDS`.

## Файлы

- `js/cards.js` — все карты, фракции, способности
- `js/engine.js` — правила игры
- `js/ai.js` — компьютерный противник
- `js/ui.js` — интерфейс
- `css/style.css` — оформление

## Сборка APK

```bash
sudo apt-get install android-sdk-platform-23 aapt apksigner zipalign dalvik-exchange default-jdk
bash android/build_apk.sh        # → dist/tron.apk
```

APK подписывается ключом `android/debug.keystore` (пароль `android`). Ключ лежит в репозитории
специально: обновлённый APK ставится поверх старого, только если подписан тем же ключом.
Для публикации в Google Play нужен отдельный ключ, который хранят в секрете.
